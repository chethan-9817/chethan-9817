## yaho, I'm Chethan 👋

2nd year CS-DS (Computer Science & Data Science) engineering student at
St Joseph Engineering College, Mangalore.
Extremely moody, but I like building things that might actually be useful to people.

I mostly write Python, C and C++. Outside class I end up building full-stack apps,
and lately I've been messing around with LLMs and RAG a lot.

### things I've built

- **[pineapple](https://github.com/chethan-9817/pineapple)** — a crash-safe single-file key-value database in Go, plus a tool that `kill -9`s it over and over to check nothing gets lost
- **[PharmaFlow](https://github.com/chethan-9817/pharma_flow-1-)** — React + Node app for cheaper generic medicines, expiry recovery, donation and safe disposal
- **[StudentSync](https://github.com/chethan-9817/STUDENTSYNC)** — campus app for SJEC: hostel leave slips, complaints, circulars, digital student ID with QR passes, and an AI doubt-solving chatbot
- **[Share-ur-ride (ArriveShare)](https://github.com/chethan-9817/Share-ur-ride)** — ride pooling for people arriving at airports and railway stations; matches riders on similar routes and splits the fare fairly
- **[OmniCalc](https://github.com/chethan-9817/A-SMART-SCINTIFIC-CALCULATOR)** — Android scientific calculator with a STEM solver and saved history
